## Comment naviguer

-  Utilisez la **barre de recherche** pour trouver un concept ou une notion spécifique
-  Cliquez sur les **liens internes** pour explorer les connexions entre les thèmes
-  Consultez le **graphe** à droite pour visualiser les dépendances entre les contenus
-  Regardez les **rétroliens** pour voir ce qui référence le document actuel
-  Survolez les liens pour obtenir un aperçu du contenu

## Organisation

Les TDs sont structurés pour faciliter votre apprentissage :
- Chaque matière a son propre dossier avec ses compositions d'équipe
- Les concepts sont interconnectés pour montrer les relations
- Les notes sont mises à jour régulièrement
